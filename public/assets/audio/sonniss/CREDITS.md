# Sound effect sources

Every sound effect in this folder is an excerpt from the **Sonniss GDC Game Audio Bundle**
(downloaded from the archive.org mirror, https://archive.org/details/SonnissGameAudioGDC).

License: royalty-free, commercial use allowed, no attribution required
(https://sonniss.com/gameaudiogdc). Not for use as AI/ML training data; do not redistribute
as a standalone sound library.

Each file was trimmed, faded, converted to mono and peak-normalized to −1 dBFS (OGG Vorbis).
