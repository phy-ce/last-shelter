# Third-party visual assets

## Tabler Icons

All reusable UI glyphs—navigation, card metrics, combat status, target parts, and enemy intents—use adapted SVG paths from Tabler Icons 3.48.0. The HTML shell contains no hand-authored inline SVG icons.

- Source: https://github.com/tabler/tabler-icons
- License: MIT
- Copyright: Tabler Icons contributors
- Used icons: adjustments-horizontal, book-2, bone, bolt, cards, clock, cloud, coin, eye, eye-off, flame, hand-finger, hand-grab, heart, heart-plus, help-circle, hourglass, link, medical-cross, notebook, pill, route, shield, sword, target-arrow, trash, user-plus, user-scan, users, virus, volume, walk, wave-sine, zzz

The full license text is available at https://github.com/tabler/tabler-icons/blob/main/LICENSE.

## Kenney Fantasy UI Borders (retained, not used at runtime)

The earlier native Pixi UI pass used the files in `public/assets/ui/kenney/` for
9-slice card, panel, button and divider frames. They remain in the repository with
their license, but the current UI draws boxes and dividers procedurally and does
not load these textures at runtime.

- Source: https://kenney.nl/assets/fantasy-ui-borders (Fantasy UI Borders 1.0)
- License: CC0 (Creative Commons Zero) — credit not required
- Copyright: Kenney (www.kenney.nl)
- The original license is kept at `public/assets/ui/kenney/LICENSE.txt`.
