# 2막 계획 — 온실에서 균사 지대로

1막 `01-07 / 숨 쉬는 출구`를 나서면 이어진다. 위는 덩굴과 꽃에 먹힌 온실, 뿌리를 따라 내려가면 꽃이 썩어 버섯이 되고, 가장 깊은 곳에 균사의 심장이 있다. 온실의 식물은 땅 밑 균사가 키우고 있었다.

전막 공통 규칙(구역 번호, 전투 템포·예고 로그, 불로 지지기, 결말 문구, 연막·은밀한 이동)은 `COMMON_PLAN.md`에 있다.

## 2막 규칙

### 개화 = 2막의 소음 규칙
새 게이지를 만들지 않는다. 기존 소음을 2막에서 다른 규칙으로 쓴다.

| | 1막 | 2막 |
|---|---|---|
| 한계에 닿으면 | 턴 종료 시 배회자 합류 (반복) | **그 즉시 개화: 모든 적이 한꺼번에 깨어남 (전투당 한 번)** |
| 자연 감소 | 매 턴 −1 | 매 턴 −1 (같음) |
| 적이 올리는 소음 | 울부짖는 적만 | 잠든 적의 **행동**이 소음 +N (적·행동마다 다름) |
| 한계값 | 6 | 12 안팎 (수치 작업 때 확정) |

- **잠든 적의 행동:** 공격하지 않고 소음을 올리는 행동만 한다. 행동마다 소음량이 다르다.
  - **행동 예고**는 정해진 단어만 쓴다: `소음 +1`, `소음 +3`. 묘사를 넣지 않는다.
  - **묘사는 적 턴에 로그로** 나온다: "꽃봉오리는 몸을 떤다!" / "갓 쓴 자는 포자를 뿜는다!" 문구는 적·행동별로 데이터에 둔다.
  - 조사(은/는, 이/가)는 적 이름의 받침에 맞춰 자동으로 붙인다.
  - `COMMON_PLAN.md`의 원칙과 같다: 예고는 건조한 정해진 단어, 분위기는 로그.
- **개화 시점:** 플레이어가 행동하는 도중이라도 소음이 한계에 닿는 순간 개화한다. 깨어나는 연출이 나오고 로그에 **"피어났다..."**가 적힌다. 이후 모든 적이 공격 패턴으로 바뀐다.
- 개화 후 소음은 아무 일도 일으키지 않는다.
- **소음 설명은 막마다 다르게:** 1막은 "6 이상이면 증원", 2막은 "한계에 닿으면 개화". 상태 표시 툴팁·도감 문구를 막에 따라 바꾼다.
- 소음을 줄이는 카드는 은밀한 이동뿐. 불·감염은 개화와 연결하지 않는다.

### 구역별 추가 규칙
- **온실:** 덩굴이 생존자를 붙잡는다 (기존 붙잡힘 규칙).
- **균사 지대:** 적 공격은 체력 피해가 작고 감염을 크게 올린다. 감염은 체력 대신 **환각**으로 벌을 준다 (매 턴 체력 감소 대신 환각 누적, 고열은 유지).

### 잠식 (감염이 끝까지 찼을 때)
- 감염이 한계(20 안팎)에 닿으면 즉사가 아니라 **잠식** 디버프가 걸린다. 카운트다운 3턴(초안), 내 턴 시작마다 1씩 준다.
- 그 안에 감염을 한계 아래로 치료하면(응급 처치·항생제·불로 지지기 등) 풀린다. 0이 되면 사망 → "당신은 정원의 일부가 되었다."
- 잠식은 전투가 끝나도 이어진다.

### 환각
- **환영 적:** 보류 — 지금은 만들지 않는다.
- **거짓 예고:** 틀린 예고도 진짜처럼 보인다. 적이 실제로 행동할 때 드러난다.
- **흔들리는 시야:** 규칙 효과 없이 화면 연출로 항상 깐다. 환각이 높을수록 강해진다.
- 손패 가리기는 넣지 않는다.

## 연출

### ★ 필수: 소음에 따라 가장자리에서 번져 들어오는 덩굴·균사
- 소음이 오를수록 화면 가장자리에서 **덩굴(온실)** 또는 **균사 핏줄(균사 지대)**이 안쪽으로 번져 들어온다. 소음 숫자를 보지 않아도 개화가 가까워지는 게 풍경으로 보여야 한다.
- 소음이 줄면(자연 감소, 은밀한 이동) 덩굴·균사가 움츠러들며 물러난다.
- 개화 순간 한꺼번에 밝게 타오르고, 이후 그 전투 동안 화면을 덮은 채 남는다.
- 전환 구역 `02-04 / 뿌리 계단`에서는 덩굴과 균사가 섞여 들어온다.
- 구현: Pixi에서 덩굴·균사 텍스처를 가장자리에 깔고 소음 비율로 마스크를 넓힌다. 텍스처는 아트 요청.

### 개화 순간
| 시점 | 연출 |
|---|---|
| 직전 | 소리가 멎고 빛이 꺼짐 |
| 개화 | 온실: 숙주 머리가 꽃처럼 피어남, 꽃잎 폭발 / 균사: 버섯이 일제히 터지며 포자 구름. 가장자리 덩굴·균사가 밝게 타오름 |
| 직후 | 로그 "피어났다...", 음악이 다음 마디 첫 박에 격렬한 버전으로 전환, 템포가 원래 속도 이상으로 |

### 잠식 연출
**몸과 화면은 따로 만든다.**
- **몸:** 생존자 몸에 균사 핏줄과 식물(덩굴·잎)이 번진다. 새 스프라이트 없이 겹쳐서 만든다.
  1. 이어 붙일 수 있는 균사·덩굴 그림을 생존자 위에 겹치고, 현재 생존자 그림을 마스크로 써서 몸 윤곽 안에만 보이게 한다.
  2. Pixi 필터에 노이즈 그림을 넣고 "노이즈 < 진행도"인 곳만 보이게 해서, 카운트다운이 줄수록 얼룩지듯 번지게 한다. 발끝부터 위로.
  3. 선택: 몸에서 피어오르는 포자, 어깨·머리에 자라나는 작은 버섯·잎 소품(그림별 부착 위치 표 필요).
  - 마스크가 현재 그림을 따라가므로 직업·부상 버전(약 9장)에 자동으로 맞는다.
  - 같은 방식을 2막 적의 개화 표현에도 재사용한다.
- **화면:** 전투 장면이 점점 녹색으로 물든다. 완전한 녹색이 아니라:
  - 채도를 빼고 **이끼 낀 회녹색·병든 황록색** 쪽으로 기울인다 (ColorMatrix).
  - 어두운 부분은 녹색으로, 밝은 부분은 누렇게 — 곰팡이 핀 사진 같은 느낌.
  - 가장자리부터 짙어지는 녹색 비네트. 카운트다운 마지막 턴엔 화면 대부분이 물든다.
  - 흔들리는 시야를 최대로.
  - UI 층은 물들이지 않는다 (숫자는 읽혀야 한다).

### 흔들리는 시야 구현
열에 들뜨거나 포자를 들이마신 시야. 화면이 물결치듯 일렁이고, 색이 틀어지고, 윤곽이 두 겹으로 번진다. 낮을 땐 은은하게, 높을수록 눈에 띄게.

| 효과 | 도구 | 방식 |
|---|---|---|
| 일렁임 | `DisplacementFilter` (Pixi 기본) | 노이즈 그림 기준으로 픽셀을 밀어냄. 노이즈를 천천히 흘려 물결처럼 |
| 색 틀어짐 | `ColorMatrixFilter` (Pixi 기본) | 색조를 천천히 흔들고 채도를 올렸다 내림 |
| 두 겹 윤곽 | `RGBSplitFilter` (`pixi-filters` 추가) | 빨강·파랑 채널을 반대 방향으로 몇 px 어긋나게 |
| 숨 쉬는 화면 | GSAP | 카메라가 아주 느리게 확대·축소 반복 |

| 환각 | 일렁임 | 색 틀어짐 | 두 겹 윤곽 |
|---|---|---|---|
| 낮음 | 2~3px, 아주 느리게 | 거의 없음 | 없음 |
| 중간 | 6px | 색조가 조금 흔들림 | 1~2px |
| 높음 | 12px, 빨라짐 | 눈에 띄게 흔들림 | 4px, 가끔 크게 튐 |

- 필터는 **전투 장면 층에만** 건다. UI 층은 흔들리지 않는다.
- 움직임 줄이기 설정이 켜지면 일렁임·숨 쉬는 화면은 끄고 색 변화만 약하게 남긴다.

### 구역별 분위기
| | 온실 | 균사 지대 |
|---|---|---|
| 색 | 연한 초록, 하얀 안개 | 어둠 속 청록·보라 발광 |
| 떠다니는 것 | 꽃잎, 꽃가루 | 빛나는 포자 |

### 음악
- 잔잔한 버전 → 개화 순간 같은 곡의 격렬한 버전으로 **다음 마디 첫 박에 즉시** 전환. 두 버전은 템포·키·길이가 같아야 한다.
- 두 버전을 동시에 재생하고 음량만 바꾸는 방식이라 2막 음악은 Web Audio 재생이 필요하다.
- 이상: 온실용·균사용 편곡 각각 잔잔·격렬 → 4곡. 최소: 2곡.

## 작업 나누기
- **로직 (Claude):** 막·구역 데이터, 전막 템포 값, 특수 공격 예고 로그 데이터, 정비의 불로 지지기, 사망 원인 기록과 결말 문구, 2막 소음 규칙(잠든 적 행동·즉시 개화·"피어났다..."), 막별 소음 설명 문구, 구역별 규칙, 감염→환각, 잠식, 거짓 예고, 적 패턴·수치, 연출 뼈대.
- **프레젠테이션 (Codex) 요청:** 배경(온실·전환·균사), 적 잠든/개화 그림, 덩굴·균사 가장자리 텍스처, 몸에 겹칠 균사·덩굴 그림(+선택 소품), 소음 표시의 2막용 아이콘, 음악(잔잔·격렬 세트), 효과음, Web Audio 음악 재생.

## 열린 결정
- 불로 지지기: 체력 대가, 감염 감소량, 정비당 횟수, 불 도구(화염병 등)가 필요한지.
- 잠식: 감염 한계값(20 안팎), 카운트다운 턴 수(3 안팎).
- 특수 공격 예고 문구 목록.
- 2막 소음 한계값, 잠든 적 행동별 소음량, 적별 수치.
- 직업 조정은 나중에 따로 한다 (지금 고려하지 않음).
